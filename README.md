# Customer Churn Prediction

## Project overview
This project aims to predict customer churn for a telecom company using machine learning.

## Dataset
Telco customer churn: IBM dataset from Kaggle. https://www.kaggle.com/datasets/yeanzc/telco-customer-churn-ibm-dataset

## Tech stack
Python, pandas, scikit-learn, matplotlib, seaborn.

## Project structure
- data/: raw and processed datasets
- notebooks/: exploratory analysis
- src/: preprocessing, training, evaluation
- models/: saved models
- reports/: charts and figures
